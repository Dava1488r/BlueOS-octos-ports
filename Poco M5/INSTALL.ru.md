# Инструкция по установке BlueOS 0.8.1 на POCO M5 (`rock` / `stone`) 🌸

Руководство по установке прошивки **BlueOS 0.8.1** на **Xiaomi POCO M5** (MediaTek Helio G99 / MT6789).

---

## ⚠️ ВНИМАНИЕ: Специфика MediaTek Helio G99
- Устройства на процессорах MediaTek требуют повышенной осторожности.
- **Ни в коем случае не блокируйте загрузчик (не делайте `fastboot oem lock`) на кастомной прошивке!**
- Для восстановления из бутлупа на MTK может потребоваться авторизованный сервисный аккаунт Xiaomi.

---

## 🛠 Подготовка
1. Разблокируйте загрузчик (Bootloader Unlock) через официальную утилиту Mi Flash Unlock.
2. Установите кастомное рекавери (TWRP или OrangeFox для MT6789 `rock`).
3. Скачайте установочный пакет: `BlueOS-0.8.1-rock-20261108.zip`.

---

## 🚀 Пошаговая установка через TWRP / OrangeFox

1. Переведите телефон в режим Fastboot (**Громкость Вниз + Питание**).
2. Загрузитесь в кастомное рекавери:
   ```bash
   fastboot reboot recovery
   ```
3. В рекавери обязательно сделайте **Format Data** (с подтверждением вводом слова `yes`).
4. Подключите телефон к компьютеру и прошейте архив через ADB Sideload:
   ```bash
   adb sideload BlueOS-0.8.1-rock-20261108.zip
   ```
   *Или скопируйте архив на MicroSD карту / USB OTG флешку и установите через меню `Install` в рекавери.*
5. После завершения прошивки нажмите **Reboot System**.
6. Первая загрузка займет 2-4 минуты.
