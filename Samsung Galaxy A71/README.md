# BlueOS 0.8.1 for Samsung Galaxy A71 4G (`a71` / `SM-A715F`) 🌸

Official community port of **BlueOS 0.8.1** (based on LineageOS 23.2 / Android 16) for Samsung Galaxy A71 4G (`a71`).

> **Attribution:** Based on BlueOS by GDmio (https://github.com/GDmio/BlueOS).  
> All BlueOS visual assets, themes, and UI packages are credited to the upstream BlueOS project.

---

## 📱 Device Specifications

| Parameter | Specification |
| :--- | :--- |
| **Model** | Samsung Galaxy A71 4G (`SM-A715F`, `SM-A715F/DS`) |
| **Codename** | `a71` |
| **SoC** | Qualcomm Snapdragon 730 (SM7150) |
| **GPU** | Adreno 618 |
| **Base ROM** | LineageOS 23.2 (Android 16) |
| **BlueOS Version** | 0.8.1 (Arona) |
| **Status** | Pre-release (Community Port / Untested on Physical Hardware) |

---

## 📦 Release Files

- `BlueOS-0.8.1-a71-20261109.zip` — Full flashable recovery package (sideload via Lineage Recovery / TWRP)
- `recovery.tar` — Odin flashable recovery for Samsung Download Mode (AP slot)
- `recovery.img` — Stock Lineage/BlueOS Recovery
- `boot.img` — Boot / Kernel partition
- `dtbo.img` — Device Tree Blob Overlay
- `vbmeta.img` — Android Verified Boot metadata
- `SHA256SUMS` — Verification checksums
