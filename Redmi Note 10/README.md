# BlueOS 0.8.1 for Xiaomi Redmi Note 10 4G (`mojito` / `sunny`) 🌸

Official community port of **BlueOS 0.8.1** (based on LineageOS 24.0 / Android 17) for **Xiaomi Redmi Note 10 4G** (`mojito` / `sunny`).

> **Attribution:** Based on BlueOS by GDmio (https://github.com/GDmio/BlueOS).  
> All BlueOS visual assets, themes, and UI packages are credited to the upstream BlueOS project.

---

## 📱 Device Specifications

| Parameter | Specification |
| :--- | :--- |
| **Model** | Xiaomi Redmi Note 10 4G |
| **Codename** | `mojito` / `sunny` |
| **SoC** | Qualcomm Snapdragon 678 (SM6150-AC) |
| **GPU** | Adreno 612 |
| **Base ROM** | LineageOS 24.0 (Android 17) |
| **BlueOS Version** | 0.8.1 (Arona) |
| **Status** | Pre-release (Community Port / Untested on Physical Hardware) |

---

## 📦 Release Files

- `BlueOS-0.8.1-mojito-20261109.zip` — Recovery ROM package (flash or sideload via TWRP / PBRP / OrangeFox)
- `boot.img` — Kernel boot image
- `dtbo.img` — Device Tree Blob Overlay
- `vendor_boot.img` — Vendor boot partition
- `SHA256SUMS` — Cryptographic verification checksums
