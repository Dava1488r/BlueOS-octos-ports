# Инструкция по установке BlueOS 0.8.1 на Redmi 7A (`pine` / `mi439`) 🌸

Пошаговое руководство по прошивке оптимизированной версии **BlueOS 0.8.1** для **Xiaomi Redmi 7A (`pine`)** и платформы **mi439** (Redmi 7A, Redmi 8, Redmi 8A).

---

## ⚡ Особенности версии для 2 ГБ ОЗУ
В сборку интегрирован специальный профиль управления памятью:
- **ZRAM 2 ГБ** с алгоритмом сжатия LZ4.
- Оптимизированный Dalvik heap (`heapgrowthlimit=128m`) для предотвращения выгрузки лаунчера.
- Отключены тяжелые графические размытия (Blur), нагружающие Adreno 505.

---

## 🛠 Подготовка
1. Разблокируйте загрузчик (Bootloader Unlock) через официальную утилиту Mi Flash Unlock.
2. Установите кастомное рекавери (**OrangeFox** или **TWRP** для `pine`/`mi439`).
3. Скачайте архив прошивки `BlueOS-0.8.1-pine-20261108.zip`.

---

## 🚀 Пошаговая установка через OrangeFox / TWRP

1. Переведите телефон в режим Recovery (**Громкость Вверх + Питание**).
2. Перейдите в меню **Wipe** -> выберите **Format Data** и введите `yes` для подтверждения.
3. Дополнительно в меню **Advanced Wipe** отметьте:
   - `Dalvik / ART Cache`
   - `Cache`
   - `System`
   - `Vendor`
   - `Data`
   и сделайте свайп для очистки.
4. Подключите телефон к компьютеру и прошейте архив через ADB Sideload:
   ```bash
   adb sideload BlueOS-0.8.1-pine-20261108.zip
   ```
   *Либо скопируйте архив на MicroSD карту и прошейте через раздел `Install` в рекавери.*
5. После завершения прошивки нажмите **Reboot System**.
6. Первая загрузка займет 3-5 минут.
