# Чистая установка BlueOS 0.8.1 на Samsung Galaxy A71 4G (`a71`) 🌸

Пошаговое руководство по установке **BlueOS 0.8.1** (Android 16 / база LineageOS 23.2) на **Samsung Galaxy A71 4G** (`SM-A715F`).

---

## ⚠️ Важные предупреждения

- Прошивка кастомного ПО навсегда активирует флаг **KNOX** (0x1) и полностью форматирует внутреннюю память.
- **Обязательно сохраните все важные данные** (фото, контакты, 2FA) на внешний носитель или ПК перед началом.
- Убедитесь, что заряд аккумулятора смартфона не менее 60%.
- Перед прошивкой разблокируйте загрузчик (OEM Unlock) через режим загрузки (Download Mode).

---

## 🛠 Необходимые компоненты

1. **Драйверы Samsung USB** (для Windows) или `heimdall` / `adb` / `fastboot` (для Linux/macOS).
2. **Odin v3.14.4** (Windows) или **Heimdall CLI** (Linux/macOS).
3. Скачанные файлы из релиза BlueOS:
   - `BlueOS-0.8.1-a71-20261109.zip` — архив с прошивкой
   - `recovery.tar` — рекавери для прошивки через Odin в слот AP
   - `vbmeta.img` — образ метаданных с отключенной проверкой целостности

---

## 🚀 Пошаговая инструкция

### Шаг 1: Разблокировка загрузчика (Bootloader)
1. Включите меню разработчика: **Настройки** -> **Сведения о телефоне** -> **Сведения о ПО** -> нажмите на **Номер сборки** 7 раз подряд.
2. В появившемся меню **Параметры разработчика** включите **Заводская разблокировка** (OEM Unlocking) и **Отладка по USB**.
3. Выключите телефон. Зажмите одновременно **Громкость Вверх + Громкость Вниз** и подключите телефон к ПК через USB-кабель, пока не появится бирюзовый экран с предупреждением Download Mode.
4. Зажмите **Громкость Вверх** (длительное нажатие) для входа в меню разблокировки загрузчика и подтвердите (телефон сбросится до заводских настроек).

### Шаг 2: Прошивка Recovery через Odin
1. Выключите телефон. Зажмите **Громкость Вверх + Громкость Вниз** и вставьте USB-кабель. Нажмите **Громкость Вверх** один раз для входа в **Download Mode**.
2. Запустите **Odin v3.14.4** на ПК:
   - Убедитесь, что устройство определилось (голубое поле `ID:COM`).
   - Во вкладке **Options** обязательно **СНИМИТЕ галочку "Auto Reboot"** (это критично, иначе стоковая система перезапишет рекавери при старте).
   - Нажмите кнопку **AP** и выберите файл `recovery.tar`.
   - Нажмите **Start** и дождитесь зеленой надписи `PASS!`.
3. Отключите USB-кабель. Зажмите и удерживайте **Громкость Вниз + Питание** ровно 7 секунд для выхода из Download Mode. Как только экран погаснет, мгновенно перехватите пальцы и зажмите **Громкость Вверх + Питание**, удерживая их до появления меню BlueOS / LineageOS Recovery.

### Шаг 3: Сброс данных (Format Data)
1. В меню рекавери перемещайтесь качелькой громкости и подтверждайте кнопкой питания.
2. Выберите **Factory Reset** -> **Format data / factory reset**.
3. Подтвердите форматирование.

### Шаг 4: Прошивка BlueOS ROM
1. В главном меню рекавери выберите **Apply update** -> **Apply from ADB**.
2. Подключите телефон к компьютеру по USB.
3. Откройте командную строку/терминал на компьютере и выполните:
   ```bash
   adb sideload BlueOS-0.8.1-a71-20261109.zip
   ```
4. Дождитесь завершения передачи и установки (обычно индикатор на ПК доходит до ~47% и появляется надпись `Step 2/2` или `Total xfer: 1.00x`).
5. (Если рекавери выдаст предупреждение `Signature verification failed`, выберите **Yes** для продолжения).

### Шаг 5: Перезагрузка в систему
1. В главном меню выберите **Reboot system now**.
2. Первый запуск займет 2-3 минуты.
3. Добро пожаловать в Кивотос, Сэнсэй! 🌸
