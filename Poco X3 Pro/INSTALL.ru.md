# Инструкция по чистой установке BlueOS 0.8.1 на POCO X3 Pro (`vayu` / `bhima`) 🌸

Полное руководство по установке прошивки **BlueOS 0.8.1** (Android 17 / LineageOS 24.0 base) на **Xiaomi POCO X3 Pro**.

---

## ⚠️ Важное предупреждение
- Установка кастомной прошивки форматирует внутреннюю память устройства. **Сделайте резервную копию всех важных данных!**
- Загрузчик (Bootloader) смартфона должен быть разблокирован (через Mi Flash Unlock).
- Уровень заряда аккумулятора должен быть не менее 50%.

---

## 🛠 Подготовка
1. Установите драйверы Android ADB и Fastboot на ПК.
2. Скачайте файлы прошивки из репозитория:
   - `BlueOS-0.8.1-vayu-20261108.zip` — установочный архив ROM
   - `boot.img` — образ ядра
   - `dtbo.img` — оверлей дерева устройств
   - `recovery.img` — кастомное рекавери BlueOS / LineageOS (или используйте OrangeFox)
   - `vbmeta.img` — образ верификации

---

## 🚀 Пошаговая установка

### Шаг 1: Перевод телефона в режим Fastboot
1. Выключите смартфон.
2. Зажмите и удерживайте комбинацию кнопок: **Громкость Вниз + Кнопка Питания**, пока на экране не появится надпись FASTBOOT (или логотип зайца/робота).
3. Подключите телефон к компьютеру оригинальным кабелем USB Type-C.

### Шаг 2: Прошивка загрузочных разделов через Fastboot
Откройте терминал на ПК в папке со скачанными файлами и выполните:
```bash
# Проверка подключения
fastboot devices

# Отключение верификации vbmeta
fastboot --disable-verity --disable-verification flash vbmeta vbmeta.img

# Прошивка ядра и дерева устройств
fastboot flash boot boot.img
fastboot flash dtbo dtbo.img

# Прошивка рекавери
fastboot flash recovery recovery.img

# Перезагрузка в рекавери
fastboot reboot recovery
```

### Шаг 3: Очистка разделов (Wipe / Format Data)
1. В рекавери перейдите в **Factory Reset** (или раздел Очистка / Wipe).
2. Выберите **Format data / factory reset** и подтвердите действие.
   > [!IMPORTANT]
   > Это обязательный шаг для снятия заводского шифрования MIUI/HyperOS!

### Шаг 4: Прошивка архива BlueOS
1. В главном меню рекавери выберите **Apply update** -> **Apply from ADB** (режим Sideload).
2. На компьютере в терминале запустите прошивку архива:
```bash
adb sideload BlueOS-0.8.1-vayu-20261108.zip
```
3. Дождитесь завершения процесса (на экране появится `Step 2/2` или `Total xfer: 1.00x`).

### Шаг 5: Перезагрузка в систему
1. Выберите в рекавери **Reboot system now**.
2. Первая загрузка может занять 2-3 минуты.
3. Добро пожаловать в Кивотос, Сенсей! 🌸
