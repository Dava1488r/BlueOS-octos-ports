# Чистая установка BlueOS 0.8.1 на Redmi Note 10 4G (`mojito` / `sunny`) 🌸

Пошаговая инструкция по установке **BlueOS 0.8.1** (база LineageOS 24.0 / Android 17) на **Xiaomi Redmi Note 10 4G**.

---

## ⚠️ Важные примечания

- Прошивка кастомного ROM полностью стирает внутреннюю память. **Создайте резервную копию всех важных данных** перед началом.
- Загрузчик (Bootloader) должен быть официально разблокирован через **Mi Unlock**.
- Заряд аккумулятора должен быть не менее 50%.
- Сборка является чистой **64-битной** (старые 32-битные приложения работать не будут).

---

## 🛠 Необходимые компоненты

1. Установленные драйверы ADB и Fastboot на ПК.
2. Скачанные файлы из релиза BlueOS:
   - `BlueOS-0.8.1-mojito-20261109.zip` — архив с прошивкой
   - `boot.img` — образ ядра
   - `dtbo.img` — Device Tree Blob Overlay
   - `vendor_boot.img` — Vendor boot partition

---

## 🚀 Пошаговая инструкция

### Шаг 1: Переход в режим Fastboot
1. Выключите телефон.
2. Зажмите и удерживайте **Громкость Вниз + Кнопку питания**, пока на экране не появится заяц FASTBOOT или логотип Fastboot.
3. Подключите телефон к компьютеру по USB.

### Шаг 2: Прошивка разделов ядра через Fastboot
Откройте командную строку/терминал в папке со скачанными файлами:
```bash
# Проверка подключения смартфона
fastboot devices

# Прошивка разделов ядра
fastboot flash boot boot.img
fastboot flash dtbo dtbo.img
fastboot flash vendor_boot vendor_boot.img

# Перезагрузка в рекавери
fastboot reboot recovery
```

### Шаг 3: Форматирование данных (Format Data)
1. В рекавери (TWRP / OrangeFox / PBRP / Lineage Recovery) перейдите в меню **Очистка (Wipe)**.
2. Выберите **Format Data** (введите `yes`), чтобы расшифровать раздел и удалить старые данные.

### Шаг 4: Прошивка BlueOS ROM
1. В рекавери выберите **Apply update** -> **Apply from ADB** (или прошейте zip-файл напрямую с флешки/OTG).
2. На компьютере выполните команду:
```bash
adb sideload BlueOS-0.8.1-mojito-20261109.zip
```
3. Дождитесь окончания установки (`Step 2/2` или `Total xfer: 1.00x`).

### Шаг 5: Перезагрузка в систему
1. Нажмите **Reboot system now**.
2. Первый запуск займет 2-3 минуты.
3. Добро пожаловать в Кивотос, Сэнсэй! 🌸
